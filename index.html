03Automation Lab

Scripts and tools I have built to take repetitive work off the team.

Each entry says whether it was used on a live project or is still an experiment. Time savings are only quoted where they were measured.

  1. 01Used on a project

    Sheet creation and export with ISO 19650 naming

    ILMI Science & Innovation Center, Riyadh

    Problem
    Creating sheets one by one and exporting each to PDF and CAD by hand, then renaming every file to the project naming standard.
    Solution
    Dynamo scripts that create the sheets and export them to PDF and CAD with ISO 19650 file names.
    • Dynamo
    • Revit
  2. 02Experiment

    Parametric wave facade generator

    What it does
    A Dynamo graph with a CPython3 node that builds a wave facade in Revit from sliders: facade size, fin spacing and thickness, wave amplitude and count, panel size and joint gap. It can create vertical fins, triangular panels or both, and places them as Generic Model elements.
    • Dynamo
    • Python (CPython3)
    • Revit API
  3. 03Used on a project

    Custom hatch patterns with pyRevit

    ILMI Science & Innovation Center, Riyadh

    Solution
    Hatch patterns created with pyRevit for the interior fit-out model and shop drawings.
    • pyRevit
    • Revit
